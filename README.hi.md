## सुविधाएँ

### समर्थित लिंक

- वीडियो (BV / av), कई हिस्सों वाले वीडियो, कलेक्शन, एनीमे और फ़िल्में (ep / ss / md), पेड कोर्स
- पसंदीदा फ़ोल्डर, "बाद में देखें", किसी अपलोडर (UP 主) के वीडियो, कलेक्शन और सीरीज़ (कीवर्ड से फ़िल्टर के साथ)
- ऑडियो ट्रैक और ऑडियो प्लेलिस्ट (au / am), "每周必看" (हफ़्ते की चुनिंदा सूची) और श्रेणी-वार रैंकिंग
- छोटे लिंक (b23.tv आदि) और ऐसा शेयर टेक्स्ट जिसमें लिंक के साथ शीर्षक भी हो
- एक साथ कई लिंक पार्स करें; पन्नों में बँटी सूचियाँ (पसंदीदा, अपलोडर पेज) पन्ना-दर-पन्ना लोड करें

### क्वालिटी और फ़ॉर्मेट

- क्वालिटी की सूची API से आती है (8K / Dolby Vision / HDR / 4K / 1080P60 / …), प्रीमियम (大会员) वाली क्वालिटी अलग से चिह्नित
- कोडेक प्राथमिकता AVC / HEVC / AV1; ऑडियो Dolby Atmos और Hi-Res लॉसलेस FLAC तक
- पूरा वीडियो, केवल ऑडियो या केवल वीडियो; MP4 या MKV
- ffmpeg स्ट्रीम को सीधे आउटपुट फ़ाइल में कॉपी करता है, दोबारा एन्कोड नहीं करता

### अतिरिक्त सामग्री

- कवर: इमेज के रूप में सेव करें और/या फ़ाइल में जोड़ें
- CC सबटाइटल: `.srt` के रूप में सेव करें और/या वीडियो में जोड़ें
- दानमाकु (स्क्रीन पर चलती टिप्पणियाँ) `.ass` और/या `.xml` में, फ़ॉन्ट आकार, अपारदर्शिता और अवधि बदलने योग्य
- bilibili की प्रोग्रेस बार के खंडों को असली चैप्टर के रूप में लिखना
- Kodi / Jellyfin मीडिया लाइब्रेरी के लिए NFO मेटाडेटा

### कतार और नेटवर्क

- एक साथ डाउनलोड की संख्या, खंडों में मल्टी-थ्रेड डाउनलोड, स्पीड लिमिट और नेटवर्क त्रुटि पर अपने-आप दोबारा कोशिश — सब बदलने योग्य
- रोकें, फिर से शुरू करें, और ऐप दोबारा खोलने के बाद भी अधूरा डाउनलोड जारी रखें; जो काम डाउनलोड नहीं हो सकते उनका कारण साफ़ दिखता है
- प्रॉक्सी: सीधा, सिस्टम या मैन्युअल; बिल्ट-इन लेटेंसी टेस्ट से सबसे तेज़ bilibili CDN नोड चुनें
- डाउनलोड के दौरान Mac (या डिस्प्ले) को स्लीप से रोकें, और कतार पूरी होने पर सूचना पाएँ

### व्यवस्थित करना और ऑटोमेशन

- नामकरण टेम्पलेट: वेरिएबल (`{title}`, `{series}`, `{index:03}`, `{pubdate:YYYY-MM-DD}`, …), वैकल्पिक खंड और फ़ोल्डर स्तर; एकल वीडियो, कलेक्शन और एनीमे के लिए अलग-अलग
- पहले से डाउनलोड की गई सामग्री पहचानता है और पूछता / छोड़ता / दोबारा डाउनलोड करता है
- सब्सक्रिप्शन: पसंदीदा, कलेक्शन या अपलोडर को तय अंतराल पर जाँचकर नई सामग्री अपने-आप डाउनलोड करें
- पार्स इतिहास, क्लिपबोर्ड निगरानी, लाइट / डार्क थीम, बैकग्राउंड में चलना, सेटिंग्स इम्पोर्ट / एक्सपोर्ट
- GitHub Releases से ऐप के अंदर अपडेट, रिलीज़ नोट्स के साथ और किसी वर्ज़न को छोड़ने का विकल्प

### AI इंटीग्रेशन

- एक लोकल [MCP](https://modelcontextprotocol.io) सर्वर, जिससे Claude जैसे AI क्लाइंट लिंक पार्स कर सकते हैं, डाउनलोड कतार में जोड़ सकते हैं और प्रगति देख सकते हैं (नीचे **MCP सर्वर** देखें)

## इंस्टॉलेशन

1. [Releases](https://github.com/wangzi6224/bili-downloader/releases/latest) से नवीनतम `.dmg` डाउनलोड करें:
   - Apple Silicon (M1 और बाद के): `bili-downloader-<version>-arm64.dmg`
   - Intel: `bili-downloader-<version>-x64.dmg`
2. dmg खोलें और **B站下载器** को **Applications** में खींचें।
3. ऐप ad-hoc साइन है पर नोटराइज़ नहीं है, इसलिए पहली बार खोलने पर macOS इसे रोक देता है। एक बार खोलने की कोशिश करें, फिर **System Settings → Privacy & Security** में जाकर **Open Anyway** पर क्लिक करें। (macOS 15 से राइट-क्लिक → Open काम नहीं करता।) या फिर यह चलाएँ:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/B站下载器.app"
   ```

macOS 12 या उसके बाद का वर्ज़न ज़रूरी है। इंटरफ़ेस अभी केवल सरलीकृत चीनी में उपलब्ध है; नीचे बताए गए लेबल चीनी में दिए गए हैं और साथ में उनका अनुवाद है।

इंस्टॉल होने के बाद ऐप खुद अपडेट जाँचता है और उन्हें सीधे इंस्टॉल कर सकता है।

## जल्दी शुरू करें

1. अपने bilibili खाते में लॉग इन करें (नीचे **लॉग इन** देखें)। लिंक पार्स करने के लिए ऐप को खाते की ज़रूरत है।
2. bilibili का लिंक कॉपी करें। ऐप पर वापस आने पर वह क्लिपबोर्ड से लिंक अपने-आप ले लेता है; या इनपुट बॉक्स में <kbd>⌘</kbd><kbd>V</kbd> दबाकर **解析** (पार्स) पर क्लिक करें।
3. डाउनलोड करने वाले आइटम चुनें: सब चुनें, चयन उलटें, <kbd>Shift</kbd>-क्लिक से रेंज चुनें, या शीर्षक या क्रमांक (जैसे `1-5,7`) से फ़िल्टर करें।
4. क्वालिटी, आउटपुट प्रकार और अतिरिक्त सामग्री चुनें, फिर **下载** (डाउनलोड) पर क्लिक करें।

लिंक की जगह ये कीवर्ड भी लिख सकते हैं: `稍后再看` या `watchlater` (बाद में देखें), `每周必看` (हफ़्ते की चुनिंदा सूची), `排行榜` (रैंकिंग)।

## लॉग इन

लॉग इन करने पर आपको वे क्वालिटी और सामग्री मिलती हैं जिनकी अनुमति आपके खाते को है (1080P और ऊपर, प्रीमियम सामग्री)। इसके तीन तरीक़े हैं:

- **从浏览器导入** (ब्राउज़र से इम्पोर्ट): Chrome, Edge, Brave, Arc, Vivaldi, Chromium या Firefox की लॉग इन कुकीज़ का दोबारा उपयोग। macOS, Chrome, Edge और Brave के डेटा की सुरक्षा करता है, इसलिए पहले **System Settings → Privacy & Security → Full Disk Access** में इस ऐप को अनुमति दें और ऐप दोबारा शुरू करें। Chromium-आधारित ब्राउज़र से इम्पोर्ट करते समय Keychain एक्सेस की अनुमति भी माँगी जाती है।
- **在应用内登录** (ऐप में लॉग इन): bilibili का आधिकारिक लॉग इन पेज खोलता है — QR कोड, पासवर्ड या SMS से लॉग इन।
- **手动粘贴 Cookie** (कुकी खुद पेस्ट करें): सेमीकोलन से अलग की गई कुकी स्ट्रिंग, या किसी ब्राउज़र एक्सटेंशन से एक्सपोर्ट किया गया JSON।

ऐप शुरू होने पर, विंडो पर लौटने पर, लिंक पार्स करते समय और जब भी API सत्र समाप्त होने की सूचना दे, ऐप लॉग इन की स्थिति जाँचता है। लॉग इन की अवधि ख़त्म होने पर वह दोबारा लॉग इन करने को कहता है, नई स्ट्रीम लेना रोक देता है और लॉग इन के बाद कतार अपने-आप फिर शुरू कर देता है। लॉग आउट करने पर सिर्फ़ ऐप की अपनी कुकीज़ हटती हैं; आपके ब्राउज़र का लॉग इन बना रहता है।

## MCP सर्वर

ऐप एक लोकल [Model Context Protocol](https://modelcontextprotocol.io) सर्वर चला सकता है, ताकि AI क्लाइंट आपकी डाउनलोड कतार के साथ काम कर सकें।

1. **设置 → 网络与高级 → MCP 服务** (सेटिंग्स → नेटवर्क और उन्नत → MCP सर्वर) में जाकर इसे चालू करें।
2. उसी सेक्शन के बटनों से क्लाइंट कॉन्फ़िगरेशन (JSON) या Claude Code कमांड कॉपी करें; इनमें आपका एक्सेस टोकन पहले से भरा होता है।

```json
{
  "mcpServers": {
    "bili-downloader": {
      "type": "http",
      "url": "http://127.0.0.1:39231/mcp",
      "headers": { "Authorization": "Bearer <your-token>" }
    }
  }
}
```

```bash
claude mcp add --transport http bili-downloader http://127.0.0.1:39231/mcp --header "Authorization: Bearer <your-token>"
```

| टूल | विवरण |
| --- | --- |
| `get_status` | लॉगिन और प्रीमियम (大会员) की स्थिति, कतार का सारांश, डाउनलोड फ़ोल्डर में खाली जगह और ध्यान देने लायक बातें। सबसे पहले इसे कॉल करें |
| `parse_link` | bilibili लिंक (वीडियो, कलेक्शन, एनीमे, कोर्स, पसंदीदा, अपलोडर…) पार्स करता है; सूचियों के पेज अपने-आप पलटे जाते हैं। आइटम की ID स्थिर रहती है; नतीजे हिस्सों में पढ़े जा सकते हैं और कई हिस्सों वाले वीडियो खोले जा सकते हैं |
| `download_batch` | पूरे लिंक या चुने गए आइटम को एक बैच के रूप में कतार में जोड़ता है और `batch_id` लौटाता है। पहले से डाउनलोड हो चुके आइटम डिफ़ॉल्ट रूप से छोड़ दिए जाते हैं, और वही अनुरोध दोबारा भेजने पर कुछ भी दो बार डाउनलोड नहीं होता |
| `get_batch_status` | बैच की प्रगति: हर स्थिति में कितने काम, गति, बचा हुआ अनुमानित समय, असल क्वालिटी, विफलता के कारण। `wait_seconds` से बदलाव का इंतज़ार किया जा सकता है |
| `list_batches` | हाल में भेजे गए बैच |
| `list_tasks` | काम पेज-दर-पेज दिखाता है, बैच, स्थिति या शीर्षक से फ़िल्टर के साथ |
| `control_tasks` | कई कामों को एक साथ रोकता, फिर शुरू करता, दोबारा कोशिश करता, फिर से डाउनलोड करता या हटाता है (डाउनलोड हो चुकी फ़ाइलें कभी नहीं हटतीं) |
| `get_settings` / `update_settings` | डाउनलोड फ़ोल्डर, एक साथ डाउनलोड की संख्या, थ्रेड, गति सीमा, अपने-आप दोबारा कोशिश, डिफ़ॉल्ट क्वालिटी और डाउनलोड विकल्प पढ़ता या बदलता है |

सर्वर केवल `127.0.0.1` पर सुनता है (पोर्ट बदला जा सकता है), Bearer टोकन ज़रूरी है, और DNS rebinding से बचाव के लिए `Host` / `Origin` हेडर जाँचता है। टोकन कभी भी नया बनाया जा सकता है।

## सीमाएँ

- DRM से सुरक्षित, क्षेत्र-प्रतिबंधित, या आपके खाते के लिए अनुपलब्ध सामग्री डाउनलोड नहीं की जा सकती। ऐसे काम **无法下载** (डाउनलोड नहीं हो सकता) के रूप में कारण सहित चिह्नित होते हैं।
- केवल macOS।

## सोर्स से बिल्ड करें

macOS, Node.js 22.12 या उसके बाद का वर्ज़न और npm चाहिए।

```bash
git clone https://github.com/wangzi6224/bili-downloader.git
cd bili-downloader
npm install
npm run dev          # डेवलपमेंट मोड
npm test             # यूनिट टेस्ट
npm run typecheck    # टाइप जाँच
npm run build:mac    # dist/ में x64 और arm64 के dmg / zip बनाएँ
```

डेवलपमेंट की प्रक्रिया के लिए [CONTRIBUTING.md](CONTRIBUTING.md) (अंग्रेज़ी में) और पैकेजिंग व रिलीज़ के लिए [docs/RELEASING.md](docs/RELEASING.md) (चीनी में) देखें।

src/main/update             ऐप के अंदर अपडेट: update.json जाँचना, डाउनलोड सत्यापित करना, .app बदलना
src/main/mcp                लोकल MCP सर्वर
src/main/subscriptions.ts   सब्सक्रिप्शन
src/shared                  सभी प्रोसेस में साझा टाइप, लिंक पार्सिंग और नामकरण टेम्पलेट
src/renderer                यूज़र इंटरफ़ेस (React + Tailwind CSS + zustand)
scripts                     ffmpeg डाउनलोड करना, आइकन बनाना, रिलीज़ प्रकाशित करना
