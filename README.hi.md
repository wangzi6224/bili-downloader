## चार स्टेप में शुरू करें

1. **डाउनलोड करें**: [Releases](https://github.com/wangzi6224/bili-downloader/releases/latest) से अपने सिस्टम का इंस्टॉलर लें:

   | सिस्टम | फ़ाइल |
   | --- | --- |
   | macOS, Apple Silicon (M1 और बाद के) | `bili-downloader-<version>-arm64.dmg` |
   | macOS, Intel | `bili-downloader-<version>-x64.dmg` |
   | Windows x64 | `bili-downloader-<version>-x64.exe` |
   | Linux x64 | `bili-downloader-<version>-x86_64.AppImage` या `bili-downloader-<version>-amd64.deb` |

2. **लॉग इन करें**: अपने bilibili खाते में लॉग इन करें ([लॉग इन](#लॉग-इन-और-प्राइवेसी) देखें)। लिंक पार्स करने के लिए ऐप को खाते की ज़रूरत है।
3. **लिंक पेस्ट करें।** ऐप पर वापस आने पर वह क्लिपबोर्ड से लिंक अपने-आप ले लेता है; या इनपुट बॉक्स में <kbd>⌘</kbd><kbd>V</kbd> (Windows और Linux पर <kbd>Ctrl</kbd><kbd>V</kbd>) दबाकर **解析** (पार्स) पर क्लिक करें।
4. **चुनें और डाउनलोड करें।** आइटम चुनें (सब चुनें, चयन उलटें, <kbd>Shift</kbd>-क्लिक से रेंज चुनें, या शीर्षक या क्रमांक जैसे `1-5,7` से फ़िल्टर करें), क्वालिटी, आउटपुट प्रकार और अतिरिक्त सामग्री तय करें, फिर **下载** (डाउनलोड) पर क्लिक करें।

लिंक की जगह ये कीवर्ड भी लिख सकते हैं: `稍后再看` या `watchlater` (बाद में देखें), `每周必看` (हफ़्ते की चुनिंदा सूची), `排行榜` (रैंकिंग)।

## इंस्टॉलेशन

### macOS

1. [Releases](https://github.com/wangzi6224/bili-downloader/releases/latest) से नवीनतम `.dmg` डाउनलोड करें: Apple Silicon के लिए `arm64`, Intel के लिए `x64`।
2. dmg खोलें और **B站下载器** को **Applications** में खींचें।
3. ऐप ad-hoc साइन है पर नोटराइज़ नहीं है, इसलिए पहली बार खोलने पर macOS इसे रोक देता है। एक बार खोलने की कोशिश करें, फिर **System Settings → Privacy & Security** में जाकर **Open Anyway** पर क्लिक करें। (macOS 15 से राइट-क्लिक → Open काम नहीं करता।) या फिर यह चलाएँ:

   ```bash
   xattr -dr com.apple.quarantine "/Applications/B站下载器.app"
   ```

macOS 12 या उसके बाद का वर्ज़न ज़रूरी है।

### Windows

[Releases](https://github.com/wangzi6224/bili-downloader/releases/latest) से `bili-downloader-<version>-x64.exe` डाउनलोड करें और इंस्टॉलर चलाएँ। यह वर्तमान यूज़र के लिए इंस्टॉल होता है और इसके लिए एडमिनिस्ट्रेटर एक्सेस की ज़रूरत नहीं होती। इंस्टॉलर साइन नहीं है, इसलिए Windows अज्ञात प्रकाशक की चेतावनी दिखा सकता है।

### Linux

- **AppImage** (किसी भी डिस्ट्रीब्यूशन पर चलता है, खुद अपडेट होता है): `bili-downloader-<version>-x86_64.AppImage`। इसे एक्ज़ीक्यूटेबल बनाएँ और चलाएँ:

- **deb** (Debian, Ubuntu और उन पर आधारित डिस्ट्रीब्यूशन): `bili-downloader-<version>-amd64.deb`। इसे `sudo apt install ./bili-downloader-<version>-amd64.deb` से इंस्टॉल करें; इसके बाद **B站下载器** आपके ऐप्लिकेशन मेन्यू में दिखने लगेगा।

विंडो बंद करने पर ऐप बैकग्राउंड में चलता रहता है; उसे वापस लाने के लिए ट्रे आइकन पर क्लिक करें। GNOME पर इसके लिए AppIndicator एक्सटेंशन चाहिए (Ubuntu में यह पहले से मौजूद होता है)। मेन्यू बार छिपा रहता है; उसे दिखाने के लिए <kbd>Alt</kbd> दबाएँ।

## AI वॉटरमार्क हटाना

कोने में अपलोडर का वॉटरमार्क चिपका है? उससे छुटकारा पाने के दो तरीक़े हैं:

| मोड | कैसे काम करता है | किसके लिए बेहतर |
| --- | --- | --- |
| **तेज़** (डिफ़ॉल्ट) | कोने में वॉटरमार्क ढूँढ़ता है और ffmpeg के `delogo` से आसपास के पिक्सेल से उसे भर देता है | जल्दी नतीजे, स्थिर बैकग्राउंड |
| **AI रीटच** (AI 精修) | [LaMa](https://github.com/advimman/lama) इनपेंटिंग मॉडल से वॉटरमार्क के नीचे की तस्वीर फ़्रेम-दर-फ़्रेम दोबारा बनाता है | कहीं ज़्यादा साफ़ नतीजे, चलते हुए दृश्य |

- इसे डाउनलोड विकल्पों में चालू करें, या डाउनलोड सूची के ऊपर **下载后去水印** (डाउनलोड के बाद वॉटरमार्क हटाएँ) स्विच से, जिसे कभी भी बदला जा सकता है।
- डाउनलोड हो चुके वीडियो पर वॉटरमार्क के ऊपर बॉक्स बनाकर उसे ख़ुद हटाएँ।
- AI रीटच शुरू करने से पहले अनुमानित समय दिखाता है और GPU हो तो उसका उपयोग करता है। मॉडल (~200 MB) इंस्टॉलर में शामिल नहीं है; AI रीटच पहली बार इस्तेमाल करने पर यह डाउनलोड होता है और उसके SHA-256 से जाँचा जाता है।
- वॉटरमार्क हटाने पर वीडियो दोबारा एन्कोड होता है। HDR और Dolby Vision वीडियो छोड़ दिए जाते हैं।

## डाउनलोड का काम AI को सौंपें (MCP)

ऐप का लोकल [Model Context Protocol](https://modelcontextprotocol.io) सर्वर चालू करें, फिर Claude जैसे AI क्लाइंट आपके लिए bilibili पर खोज सकते हैं, डाउनलोड कतार में डाल सकते हैं और प्रगति ट्रैक कर सकते हैं। एक बार सेट हो जाए, तो बस बोल दीजिए कि क्या चाहिए:

> bilibili पर 30 से 60 मिनट लंबे "Blender tutorial" वीडियो खोजो, सबसे ज़्यादा बार देखे गए पाँच चुनो, और उन्हें एक बैच में डाउनलोड करो।

एजेंट उम्मीदवार ढूँढ़ने के लिए `search_videos`, पाँचों वीडियो को एक बैच के रूप में कतार में जोड़ने के लिए `download_batch`, और पूरा होने तक प्रगति पर नज़र रखने के लिए `get_batch_status` कॉल करता है।

> इस कलेक्शन के वे सारे वीडियो डाउनलोड करो जो मेरे पास अभी नहीं हैं, फिर AI रीटच से उनके वॉटरमार्क हटाओ: https://space.bilibili.com/…

यहाँ एजेंट कलेक्शन खोलने के लिए `parse_link`, फिर `download_batch` (पहले से डाउनलोड हो चुके आइटम छोड़ दिए जाते हैं), यह देखने के लिए `get_batch_status` कि किन फ़ाइलों पर वॉटरमार्क है और हटाने में कितना समय लगेगा, और उन्हें साफ़ करने के लिए `remove_watermark` का उपयोग करता है।

### सेटअप

1. **设置 → 网络与高级 → MCP 服务** (सेटिंग्स → नेटवर्क और उन्नत → MCP सर्वर) में जाकर इसे चालू करें।
2. उसी सेक्शन के बटनों से क्लाइंट कॉन्फ़िगरेशन (JSON) या Claude Code कमांड कॉपी करें; इनमें आपका एक्सेस टोकन पहले से भरा होता है।

```json
{
  "mcpServers": {
    "bili-downloader": {
      "type": "http",
      "url": "http://127.0.0.1:39231/mcp",
      "headers": { "Authorization": "Bearer <your-token>" }
    }
  }
}
```

```bash
claude mcp add --transport http bili-downloader http://127.0.0.1:39231/mcp --header "Authorization: Bearer <your-token>"
```

## लॉग इन और प्राइवेसी

लॉग इन कर लें, फिर आपका खाता जो भी क्वालिटी और वीडियो देख सकता है, वो सब डाउनलोड कर सकते हैं, 1080P और उससे ऊपर और प्रीमियम सामग्री समेत। इसके तीन तरीक़े हैं:

- **从浏览器导入** (ब्राउज़र से इम्पोर्ट): Chrome, Edge, Brave, Arc (केवल macOS), Vivaldi, Opera, Chromium, Firefox या Safari (केवल macOS) की लॉग इन कुकीज़ का दोबारा उपयोग।
  - अगर macOS डेटा पढ़ने से रोकता है, तो साइन-इन विंडो से उस ब्राउज़र का डेटा फ़ोल्डर चुनें। Chromium-आधारित ब्राउज़र से इम्पोर्ट करते समय Keychain ऐक्सेस की अनुमति भी माँगी जा सकती है।
  - Linux पर Chromium-आधारित ब्राउज़र कुकी की कुंजी सिस्टम कीरिंग (GNOME Keyring / libsecret) में रखते हैं। ऐप इसे `secret-tool` (`sudo apt install libsecret-tools`) से पढ़ता है, और हो सकता है कि कीरिंग अनलॉक करने को कहे। Snap और Flatpak से इंस्टॉल किया गया Firefox और Snap वाला Chromium भी समर्थित हैं।
  - Windows पर Chromium-आधारित ब्राउज़र चलते समय अपना कुकी डेटाबेस लॉक कर देते हैं, इसलिए इम्पोर्ट करने से पहले ब्राउज़र को पूरी तरह बंद करें (बैकग्राउंड में चल रही प्रोसेस समेत)। Chrome 127 या उसके बाद के वर्ज़न की लिखी कुकीज़ ऐप-बाउंड एन्क्रिप्शन का उपयोग करती हैं और इम्पोर्ट नहीं की जा सकतीं; अगर लॉग इन कुकी इनमें से है, तो इसके बजाय ऐप में लॉग इन करें या कुकी स्ट्रिंग पेस्ट करें।
- **在应用内登录** (ऐप में लॉग इन): bilibili का आधिकारिक लॉग इन पेज खोलता है — QR कोड, पासवर्ड या SMS से लॉग इन।
- **手动粘贴 Cookie** (कुकी खुद पेस्ट करें): सेमीकोलन से अलग की गई कुकी स्ट्रिंग, या किसी ब्राउज़र एक्सटेंशन से एक्सपोर्ट किया गया JSON।

ऐप शुरू होने पर, विंडो पर लौटने पर, लिंक पार्स करते समय और जब भी API सत्र समाप्त होने की सूचना दे, ऐप लॉग इन की स्थिति जाँचता है। लॉग इन की अवधि ख़त्म होने पर वह दोबारा लॉग इन करने को कहता है, नई स्ट्रीम लेना रोक देता है और लॉग इन के बाद कतार अपने-आप फिर शुरू कर देता है। लॉग आउट करने पर सिर्फ़ ऐप की अपनी कुकीज़ हटती हैं; आपके ब्राउज़र का लॉग इन बना रहता है।

**आपका डेटा कहाँ जाता है**

- आपकी bilibili कुकीज़ ऐप के अपने डेटा फ़ोल्डर में रहती हैं और केवल bilibili को भेजी जाती हैं। MCP के ज़रिए AI क्लाइंट को वे कभी नहीं लौटाई जातीं।
- डाउनलोड, जोड़ना (merge) और वॉटरमार्क हटाना, सब कुछ लोकल रूप से चलता है। कोई साइन-अप नहीं, कोई टेलीमेट्री नहीं, और बीच में हमारा कोई सर्वर नहीं।
- bilibili के अलावा ऐप केवल GitHub (अपडेट जाँचने के लिए) और ModelScope या Hugging Face (AI रीटच मॉडल एक बार डाउनलोड करने के लिए) से संपर्क करता है।
- आपके कहने पर MCP क्लाइंट खाता बदल सकता है या किसी चुने हुए खाते से लॉग आउट कर सकता है। अगर पहले ब्राउज़र बंद करना ज़रूरी हो (Windows पर ब्राउज़र चलते समय कुकी डेटाबेस लॉक रहता है), तो ऐप डायलॉग में पूछता है और केवल आप ही मंज़ूरी दे सकते हैं।

<details>
<summary>1080P / 4K / 8K क्यों नहीं चुन पा रहे?</summary>

क्वालिटी की सूची सीधे bilibili से आपके खाते के हिसाब से आती है। ऊँची क्वालिटी (1080P+ हाई बिटरेट, 4K, 8K, HDR, Dolby Vision) के लिए आम तौर पर प्रीमियम (大会员) खाता चाहिए, और हर वीडियो हर क्वालिटी में अपलोड नहीं होता।

</details>

<details>
<summary>macOS कह रहा है कि ऐप खुल नहीं सकता। अब क्या करें?</summary>

ऐप Apple से नोटराइज़ नहीं है। इसे एक बार खोलें, फिर **System Settings → Privacy & Security** में **Open Anyway** पर क्लिक करें, या [इंस्टॉलेशन](#macos) में दिया गया `xattr` कमांड चलाएँ।

</details>

<details>
<summary>Windows पर "Windows protected your PC" आ रहा है। क्या करें?</summary>

इंस्टॉलर कोड-साइन नहीं है। **More info → Run anyway** पर क्लिक करें।

</details>

<details>
<summary>किसी काम पर 无法下载 (डाउनलोड नहीं हो सकता) क्यों लिखा आ रहा है?</summary>

DRM से सुरक्षित, क्षेत्र-प्रतिबंधित, या आपके खाते के लिए अनुपलब्ध सामग्री डाउनलोड नहीं की जा सकती। काम पर इसका कारण दिखता है।

</details>

<details>
<summary>वॉटरमार्क हटाना इतना धीमा क्यों है?</summary>

AI रीटच हर फ़्रेम दोबारा बनाता है, इसलिए यह तेज़ मोड से कहीं धीमा है, ख़ासकर GPU के बिना। ऐप शुरू करने से पहले अनुमानित समय दिखाता है; जब क्वालिटी से ज़्यादा गति मायने रखे, तो तेज़ मोड इस्तेमाल करें।

</details>

<details>
<summary>क्या ऐप अंग्रेज़ी में भी है?</summary>

हाँ। v0.13.0 से इंटरफ़ेस हिन्दी सहित आठ भाषाओं में उपलब्ध है। डिफ़ॉल्ट रूप से यह सिस्टम की भाषा अपनाता है और सेटिंग्स में बदला जा सकता है।

</details>

## सीमाएँ

- DRM से सुरक्षित, क्षेत्र-प्रतिबंधित, या आपके खाते के लिए अनुपलब्ध सामग्री डाउनलोड नहीं की जा सकती। ऐसे काम **无法下载** (डाउनलोड नहीं हो सकता) के रूप में कारण सहित चिह्नित होते हैं।
- Windows x64, macOS x64 / arm64 और Linux x64 समर्थित हैं। Windows और Linux के लिए ARM वर्ज़न उपलब्ध नहीं हैं।

## सोर्स से बिल्ड करें

Windows, macOS या Linux, Node.js 22.12 या उसके बाद का वर्ज़न और npm चाहिए।

```bash
git clone https://github.com/wangzi6224/bili-downloader.git
cd bili-downloader
npm install
npm run dev          # डेवलपमेंट मोड
npm test             # यूनिट टेस्ट
npm run typecheck    # टाइप जाँच
npm run build:mac    # macOS पर: dist/ में x64 और arm64 के dmg / zip बनाएँ
npm run build:linux  # Linux पर: dist/ में x64 AppImage / deb बनाएँ
npm run build:win    # Windows पर: dist/ में x64 NSIS इंस्टॉलर बनाएँ
```

डेवलपमेंट की प्रक्रिया के लिए [CONTRIBUTING.md](CONTRIBUTING.md) (अंग्रेज़ी में) और पैकेजिंग व रिलीज़ के लिए [docs/RELEASING.md](docs/RELEASING.md) (चीनी में) देखें।
