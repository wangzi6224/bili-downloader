# GSAP Skill Router

Use the installed specialized GSAP skills alongside this router:

- **React / Next.js:** read `../gsap-react/SKILL.md`; keep animations in client lifecycle hooks and clean them up with `gsap.context()` or `useGSAP()`.
- **Sequenced motion:** read `../gsap-timeline/SKILL.md`.
- **Tweens and easing:** read `../gsap-core/SKILL.md`.
- **Scroll-driven effects:** read `../gsap-scrolltrigger/SKILL.md`.
- **Plugins:** read `../gsap-plugins/SKILL.md`.
- **Runtime cost and rendering:** read `../gsap-performance/SKILL.md`.
- **Utility methods:** read `../gsap-utils/SKILL.md`.
- **Other UI frameworks:** read `../gsap-frameworks/SKILL.md`.

Prefer motion that communicates a state change, responds to an action, and respects `prefers-reduced-motion`. Avoid decorative motion without a product purpose.
